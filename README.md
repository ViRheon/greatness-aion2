# GREATNESS — AION 2

Односторінковий сайт-візитка для української спільноти GREATNESS.

## Запуск локально

Будь-який простий static server підійде:

```bash
python -m http.server 8080
```

Після цього відкрити `http://localhost:8080` у папці проєкту.

## Деплой на GitHub Pages

Завантажити `index.html`, `styles.css` та папку `assets` у репозиторій і ввімкнути GitHub Pages для гілки, де лежить сайт.

Перед публікацією замінити `https://YOUR-DOMAIN.example/` у `index.html` на реальну адресу сайту.
