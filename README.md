## Важливо

Увесь візуальний макет збережений у вихідних зображеннях 1024px завширшки. Сторінка масштабує їх **пропорційно** на 100% ширини екрана — без фіксованого контейнера 1024px і без розтягування по висоті.

Прозорі hotspot-посилання роблять кнопки та навігацію клікабельними, не змінюючи самі зображення.

## GitHub Pages
