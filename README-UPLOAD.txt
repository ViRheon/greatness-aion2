GREATNESS AION 2 — ГОТОВИЙ САЙТ

ЩО ЗАВАНТАЖУВАТИ
1. Відкрий цю папку.
2. На GitHub відкрий свій репозиторій greatness-aion2.
3. Натисни Add file → Upload files.
4. Перетягни ВСІ файли та папку assets з цієї папки у GitHub.
5. Натисни Commit changes.

ВАЖЛИВО
- Не завантажуй ZIP-файл у репозиторій.
- У корені GitHub мають лежати index.html і styles.css.
- Папка assets має лежати поруч із ними.
- Старі файли з такими ж назвами можна замінити.

https://virheon.github.io/greatness-aion2/
